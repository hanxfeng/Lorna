前置模组（Enhanced_Secret_Admirers_And_More_News）需要的改动
最后更新：2026-11-02
目的：让洛娜模组能在「警告纸条之后」暂停纸条发放，直到下层区声望 +10；
      以及在洛娜揭面当天，压掉门口那套纸条 + 礼物。

======================================================================
一、新增一个读键的判断
======================================================================

新建文件：src\PawnshopMod\Notes\NoteGate.cs

    using UnityEngine;

    namespace PawnshopMod
    {
        internal static class NoteGate
        {
            public const string PauseUntilRepKey = "notes_pause_until_rep";
            public const string PauseDayKey = "notes_pause_day";

            public static bool Paused()
            {
                if (PlayerStore.Instance == null || StoreStation.Instance == null)
                {
                    return false;
                }

                int day = StoreStation.Instance.dayCounter;
                if (ModHelper.GetModDataInt(ModIds.Id, PauseDayKey, -1) == day)
                {
                    return true;   // 只停这一天
                }

                int until = ModHelper.GetModDataInt(ModIds.Id, PauseUntilRepKey, int.MinValue);
                if (until == int.MinValue)
                {
                    return false;  // 没设置过，正常发
                }
                return StoreReputation.GetLLReputation() < until;
            }
        }
    }

4) 新建文件：src\PawnshopMod\Notes\NoteGatePatch.cs
   —— 暂停时整段跳过原版的「开门纸条 + 礼物」：

       using HarmonyLib;

       namespace PawnshopMod
       {
           [HarmonyPatch(typeof(StartingPerkContent), nameof(StartingPerkContent.HandleSecretAdmirerOnOpenShutter))]
           internal static class Patch_SecretAdmirerGate
           {
               private static bool Prefix()
               {
                   return !NoteGate.Paused();
               }
           }
       }

   ⚠️ Prefix 返回 false 时，Harmony 仍然会执行其它 Postfix，
      所以第 1、2 条里的检查必须保留，不能省。

======================================================================
三、两个键的语义
======================================================================

  notes_pause_until_rep  int   下层区声望 < 这个值时暂停发放。
                               由洛娜模组写入/清除；键不存在时 = 不暂停。

  notes_pause_day        int   当天天数 == 这个值时暂停一整天。
                               由洛娜模组写入，只影响那一天。

  两个键都写在 Enhanced_Secret_Admirers_And_More_News 自己的 mod data 里
  （ModHelper.SetModDataInt("Enhanced_Secret_Admirers_And_More_News", ...)）。

  没有装洛娜模组时，两个键都不存在 → 行为与现在完全一致，不影响老玩家。

======================================================================
四、洛娜模组会怎么写这两个键
======================================================================

  · 警告纸条投放当天（次日开门的 OnShutterOpenedEarly）：
        SetModDataInt("Enhanced_Secret_Admirers_And_More_News", "notes_pause_until_rep", 当前声望 + 10)

  · 洛娜揭面当天（在 GenerateClient 阶段写入，早于 OnShutterDoorOpenMorning）：
        SetModDataInt("Enhanced_Secret_Admirers_And_More_News", "notes_pause_day", 当天)

======================================================================
五、不要动的地方
======================================================================

  · manifest.xml：不加能力、不加依赖、不改 ID
  · 版本号照常 +0.0.1
  · 现有纸条文案、礼物逻辑、检纸条频率都不改
  · 不要改 npc_seen_ / npc_done_ 的键名（洛娜模组在扫这两个字符串做检测）

======================================================================
六、改完自测
======================================================================

  1. 不装洛娜模组：纸条行为与现在完全一样；
  2. 手动在控制台/存档里把 notes_pause_day 设成今天：当天门口没有纸条和礼物；
  3. 把 notes_pause_until_rep 设成当前声望 +5：一直不发，声望涨到之后恢复。
