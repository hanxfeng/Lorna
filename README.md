# 神秘仰慕者洛娜（admirer_lona）

《深空当铺》（Probably Stolen 0.46D）模组，是 **《更好的神秘仰慕者和更多新闻》（`Enhanced_Secret_Admirers_And_More_News`）的附属模组**。
洛娜是前置模组里那个匿名写信的仰慕者；装上本模组后，她会作为剧情人物亲自出现。

当前版本 **0.2.0**：核心系统已实现，**文案、灯牌货品映射、立绘仍是占位**。

---

## 一、当前实现的规则

| 项 | 规则 |
| --- | --- |
| 前置 | 需启用 `Enhanced_Secret_Admirers_And_More_News`，并拥有「神秘仰慕者」天赋 |
| 首次出现声望 | 模组配置里可调（滑条 0–200，默认 150） |
| 初始好感 | `floor((激活时下层区声望 − 10) / 2)`，最小 0 |
| 好感变化 | 声望每 +2 → 好感 +1（即声望增量的 50%）；卖芬太片/梦尘 −10 |
| 好感上限 | 100；跌破 70 后不再播日常剧情 |
| 激活 | 声望第一次达到阈值即永久激活，掉回去不失效 |
| 阈值前 | 10% 概率顶替小偷/扒手/食物窃贼，**行为完全是普通小偷**，只是换了立绘，名字仍显示「小偷」 |
| 阈值后 | 每天 25% 出现（有小偷就顶替第一个，没有就插到队尾），两次到访至少隔 3 天 |
| 首次登场 | 跨过阈值的次日：她来买点食物（预算 200），**想买几样买几样**，玩家点离开时才说「下次见」 |
| 揭面 | 第一次见面后第 3 天或之后的第一次开门：她再来，亲手把礼物放到柜台，坦白纸条是她写的 |
| 访问类型 | 揭面之后每次先决定「来卖」或「来买」，不同时进行；特殊剧情当天只说话 |
| 来卖 | 按展示柜里的霓虹灯牌决定卖什么（食物/水/医疗/日用品/材料，没有灯牌走默认池） |
| 来买 | 收日用品/食物/医疗；拒绝一切带 `NARCOTIC` 标签的东西，**只有奥克西莫注射器（pink_injector）例外** |
| 送礼 | 来买那次，对话里选「（把东西放到柜台上）」→ 把物品放上柜成交，第一件算礼物：不收钱、加好感（价值/100，单次上限 +5）；好感 <80 时拒收价值 >300 的礼物 |
| 卖药警告 | 存档第 2 天起；声望 >60 时卖出芬太片/梦尘，次日柜台出现纸条；一天多次只算一次；第 1/2/3 次各一张，第 4 次永久离开 |
| 纸条暂停 | 警告纸条出现后，前置模组的两类纸条（日常仰慕者 + 特殊 NPC）暂停发放，下层区声望 +10 后恢复；揭面当天也会压掉门口的纸条和礼物 |
| 举报 | 可以举报，举报 = 永久离开（与卖四次药相同） |
| 离开 | 无告别演出；之后**不再出现、不再有纸条、不再有送礼、不再有剧情**；阈值前离开就永远不会出现 |
| 剧情 | 日常 4 档（70–79 / 80–89 / 90–99 / 100）；特殊 4 段（揭面、>80、>90、100）。「好感跌破 70」那段已取消 |

## 四、构建与测试

### 构建

关掉游戏，双击 `build.bat`。它会把 `AdmirerLona.dll`、`manifest.xml` 和资源目录复制到
`E:\SteamLibrary\steamapps\common\Probably Stolen\Mods\AdmirerLona\`。

### 游戏内测试

1. 启动游戏 →「模组」菜单：先启用 `Enhanced_Secret_Admirers_And_More_News`，再启用「神秘仰慕者洛娜」；
2. 需要一个带「神秘仰慕者」天赋的存档（新档选天赋，或改造现有存档）；
3. F9 → **Special** 页 →「Lorna 测试面板」，里面可以：
   - 让下一位顾客是洛娜（来买 / 来卖 / 只说话）
   - 初见面两段（第一段买食物 / 第二段揭面）
   - 直接看某一档日常剧情（档 1–4）
   - 直接看五段特殊剧情
   - 让下一位顾客是小偷形态（150 前的样子）
   - 三条警告纸条：直接把对应纸条放到柜台（不计数、不触发暂停）
   - 打印状态到 F8、重置洛娜状态
4. 测试按钮只是**排队**：下一次开门生成顾客时才生效。

### 文案

文案在 `content/lona_notes_zh.md`、`content/lona_first_zh.md` 里改，然后：

```
python content/build_localization.py
```

会重新生成 `src\AdmirerLona\Localization\zh.csv`；`build.bat` 会把它复制进游戏。
代码里对每一条都有 fallback，CSV 缺了也能跑。

### 日志

F8 控制台过滤 `[神秘仰慕者洛娜]`。前置模组私有键检测失败时**只写控制台红字，不弹窗**。

## 六、三条硬约定

1. **不要引用 `PawnshopMod.dll`**——扫描器会判 `unlisted-reference` 并拒绝启用。
2. 依赖写在 `manifest.xml` 的 `<Prerequisites><Mod>Enhanced_Secret_Admirers_And_More_News</Mod></Prerequisites>`。
3. 运行时互调只用 `ModHelper`（读数据）或反射（需声明 `reflection-external`）。

## 七、已知限制

- **纸条暂停依赖前置模组的新版本**：洛娜模组只负责写 `notes_pause_until_rep` / `notes_pause_day`
  两个键，需要前置模组按 `前置模组修改.txt` 改过之后才会真的生效；没改之前这两个键没有效果。
- 加载时会扫描前置模组 DLL 里的 `npc_seen_` / `npc_done_` 做结构检测，找不到就整体停用洛娜并在 F8 报错。
- 送礼目前只在她「来买」的访问里可用（游戏不允许给纯卖家放物品）。
- 「一键清空柜台」卖药只能按「柜台里有没有药 + 本次是否真的成交」判断，无法分辨卖了几种。
- 玩家在对话记录里会看到一行「来自 神秘仰慕者洛娜」，这是游戏的模组内容标识，暂时没去掉。
